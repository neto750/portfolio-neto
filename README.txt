PORTFÓLIO - NETO

Arquivos:
- index.html: estrutura e conteúdo
- style.css: visual e responsividade
- script.js: menu mobile e ano automático

COMO USAR
1. Extraia a pasta.
2. Abra index.html no navegador ou abra a pasta no VS Code.
3. Edite o conteúdo do index.html para completar suas informações.
4. Publique os arquivos na raiz do repositório GitHub para ativar o GitHub Pages.

ANTES DE PUBLICAR, PERSONALIZE:
- Confirme o nome/apelido que deseja exibir.
- Adicione o link correto do repositório da Pokédex e do Conversor PTAX nos botões "Ver código".
- Se ainda não quiser divulgar LinkedIn, troque o link pelo seu perfil real ou remova o botão.
- Atualize as tecnologias conforme seu domínio atual.
- Revise os textos para refletirem exatamente o que cada projeto já faz.

O projeto não usa backend, banco de dados ou dependências de instalação.
